# TuneFinder

This is a Next.js application built with Firebase Studio.

TuneFinder allows you to search for songs within a YouTube playlist.

## Getting Started

1.  Run the development server: `npm run dev`
2.  Open [http://localhost:9002](http://localhost:9002) with your browser to see the result.

To get started, take a look at `src/app/page.tsx`.
