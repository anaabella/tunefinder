# **App Name**: TuneFinder

## Core Features:

- Playlist URL Input: Allow users to input a YouTube playlist URL.
- Song Search: Enable users to search for specific songs within the loaded playlist by title or artist.
- Search Result Display: Display search results, including song title, artist, and a link to the YouTube video.

## Style Guidelines:

- Primary color: Soft Lavender (#E6E6FA) for a calming, musical feel.
- Background color: Off-white (#FAFAFA), nearly the same hue as the primary color, but only about 10% saturated, with maximum brightness.
- Accent color: Muted Violet (#A9A9D0) for a subtle but noticeable highlight, slightly more saturated than the primary color.
- Body and headline font: 'PT Sans', a humanist sans-serif, for a blend of modern design and readability.
- Use simple, clear icons for search and playlist navigation.
- Use subtle animations when displaying search results and loading playlist content.
